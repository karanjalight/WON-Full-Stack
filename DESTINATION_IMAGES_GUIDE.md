## Image Requirements

### Specifications
- **Dimensions**: Minimum 800x600px (recommended: 1200x900px)
- **Format**: JPG (optimized, < 300KB)
- **Aspect Ratio**: 16:9 or 4:3
- **Style**: Professional, bright, travel-focused
- **Content**: Cityscapes, landmarks, or cultural scenes

## Quick Download Steps

1. **Visit Unsplash.com** (or Pexels/Pixabay)
2. **Search** using the terms above
3. **Select** a high-quality image (minimum 1200px width)
4. **Download** the image
5. **Optimize** using TinyPNG.com (reduce file size)
6. **Rename** to match the destination number (01.jpg, 02.jpg, etc.)
7. **Replace** the file in `assets/img/destinations/`

## Image Optimization Tips

1. **Compress** images to < 300KB using TinyPNG or similar
2. **Maintain** aspect ratio (16:9 recommended)
3. **Ensure** images are sharp and professional
4. **Avoid** images with watermarks or text overlays
5. **Choose** images with good lighting and contrast
